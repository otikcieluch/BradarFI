Itroducing the Bradar File Info or bradarwatisdis inspired by Heyselcuk. \
Written in C works only on Linux.
-----------------------------------------------------------------------------
**Compile:** ```gcc bradarwatisdis.c -o bradarwatisdis``` \
**Make it function as a standalone command (system-wide):** ```sudo install -m 755 bradarwatisdis /usr/local/bin/``` \
**Combined:** ```gcc bradarwatisdis.c -o bradarwatisdis && sudo install -m 755 bradarwatisdis /usr/local/bin/```
