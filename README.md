Itroducing the Bradar File Info or bradarwatisdis inspired by Heyselcuk. \
Written in C. \
Only works on Linux. 
-----------------------------------------------------------------------------

**Install:** ```git clone https://github.com/otikcieluch/BradarFI.git && cd BradarFI``` \
**Make:** ```make``` and ```make install``` (requires sudo or doas) \
**Dependencies:** ```make``` ```gcc``` ```glibc``` ```Linux kernel``` optionally ```git``` for fetching the source
